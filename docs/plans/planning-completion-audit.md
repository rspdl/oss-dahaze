# 기획 작업공간 통합 완료 감사

이 문서는 완료 선언이 아니라 남은 요구사항을 추적하는 주 에이전트의 검수표다.
범위는 [합의된 계획](planning-workspace.md)의 1~5단계이며, 고급 정책 자동 실행과 실시간
협업은 제외한다. 현재 운영 핀 0.1.2와 미출시 planning compiler를 구분한다.

## 인터뷰 연동 재개 시점의 증거

| 요구 | 권위 있는 증거 | 상태 |
|---|---|---|
| 지속 인터뷰, 정책 제안·채택·보류 | 실제 LLM 작업과 재접속 후 대화/결정 조회 | 구현·검수 중 |
| 연결 종료와 독립적인 생성, 취소·재시도 | 별도 worker, 영속 작업, lease 회수·중복 요청·취소 경쟁 테스트 | 구현·검수 중 |
| 인터뷰 → 작성 → 명세·IA → 진단 해결 | 실제 API와 브라우저의 한 연속 시나리오 | 검수 예정 |
| 여러 문서 후보, 컴파일 게이트, 명시적 적용 | 기존 기획 API 테스트, 실제 HTTP 오류 후보·중복 적용·복원 검수 | AI 생성 경로 통합 검수 필요 |
| 회색 와이어프레임, 환경별 해상도, 입력·결과 선택 | 항공 사례, 실제 390×844 viewport 및 클릭·팝업·입력 복원 | 기존 수동 경로 검수 통과 |
| 의미 편집과 원문/진단 연결 | 실제 UI 제목 편집 → 컴파일 후보 → 적용 및 진단 원문 이동 | 미출시 compiler에서 검수 통과 |
| 업무 데이터 확보·결과·권한·제한된 복구 | core #38 conformance와 별도 경로 탐색 비교, 항공 정상/반례 fixture | 미출시 compiler에서 검수 통과 |
| 전달·복원·비교와 UI/JSON/MCP 일치 | 실제 전달 JSON과 MCP 동일성, 원자적 복원·경쟁 검사 | 기존 수동 경로 검수 통과 |
| 30/60/100 화면, 2/4 사용 환경 | 합성 항공 프로젝트의 실제 브라우저 측정 | 선택 반응 개선 필요 |
| 배포할 compiler와 저작 prompt/grammar 일치 | 정식 wheel, 버전 승격·문서 재컴파일·생성 검수 | 정식 버전 반영 전 |
| 최종 하네스·CI | 변경 최종 커밋의 전체 하네스와 원격 CI | AI 변경 이후 재실행 필요 |

원격 dahaze CI `35777624894`와 core CI `35775352261`는 AI 연동 재개 전 커밋에서
통과했다. 이후 코드가 추가되므로 이 결과로 새 AI 구현을 통과 처리하지 않는다.

## 규모 검수의 초기 측정

주 에이전트가 합성 프로젝트 세 개를 별도 로컬 검수 DB에 생성했다. 30/60 화면은
15화면 항공 fixture를 각각 2/4개 독립 모듈로 복제했다. 100화면은 6개 항공 모듈과
입력·목록을 가진 추가 10화면으로 구성했다. 파일 사이 의미 공유를 검증하는 사례가 아니다.
모든 프로젝트의 컴파일 진단은 최종 fixture에서 0건이다.

1280×900 Chromium, Next 개발 서버, 많은 데이터 샘플, PC 환경을 기준으로 실제 휠과
드래그를 조작했다. 선택 반응은 DOM change부터 두 번째 animation frame까지의 시간이며,
그래프 이동 애니메이션이 끝나는 시간이나 배포 성능의 보장이 아니다.

| 화면 | 환경 | pan/zoom 프레임 p95 | 선택 반응 최댓값(5회) |
|---:|---:|---:|---:|
| 30 | 4 | 18.3ms | 102.5ms |
| 60 | 4 | 18.4ms | 119.9ms |
| 100 | 4 | 18.6ms | 142.0ms |
| 30 | 2 | 18.5ms | 102.3ms |
| 60 | 2 | 18.3ms | 118.3ms |
| 100 | 2 | 18.5ms | 134.2ms |

화면 선택 시 ReactFlow가 다시 마운트되는 구현을 보완 대상으로 확인했다. 위 수치는
개선 이전 결과다. 최종 선택 반응과 viewport 표시 여부를 다시 확인해야 한다.

## 실제 API 첫 연결

사용자의 기존 키 재사용 승인 후 원래 env 파일을 읽기만 하고, 키를 복사하거나 출력하지 않았다.
기존 모델 설정 `gpt-4.1`은 custom grammar 요청을 HTTP 400으로 거절했다.
검수 프로세스에서만 저장소 기본 모델 `gpt-5-nano`를 사용한 요청은 약 40초에 성공했다.
생성된 최소 예약 명세를 별도 planning compiler로 검사한 결과 오류 0건과
`RSPDL-DATA-W001` 경고 1건이었다. 이는 단일 생성·컴파일 연결의 증거이며 프로젝트
인터뷰·작업 복구·진단 해결 반복 전체가 완성됐다는 증거는 아니다.
