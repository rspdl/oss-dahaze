### 상황

에이전트가 도구를 사용하여 여러 파일을 순차적으로 편집하고, 삭제하고, 추가할 수 있음. 하지만 문서들은 구조상 다른 팀 구성원들에게 보여지거나 수정될 수 있음.

특히 삭제 작업의 경우, 내가 폴더를 삭제하려고 할 때 구성원 중 누군가가 해당 폴더에 파일을 넣어서 원하지 않게 해당 파일이 같이 삭제되는 등의 이슈가 발생할 수 있음.

### 나의 판단

이런 동시성 문제를 고민하기에는 아직 너무 기능이 없고, 실제 사용자의 테스트를 받지 않았음. 따라서 개인이 하나의 개정으로 동시에 하나의 세션만으로 한다고 가정하는게 좋아보임.

삭제 동작 같은 위험한 동작은 직접하도록 바꿔서 구현의 복잡도를 낮추고, 좀 더 제품의 핵심 가치인 기획 검토나, UX 흐름 검토에 신경을 쓰는게 좋아 보임
